Low Power Mode — decode test

Turn Low Power Mode ON. Only one animation is loaded at a time, so this matches the real page.

What each one isolates. A vs B changes the frame count at the same size — that tests whether more frames help or hurt. A vs C changes the size at the same frame count — that tests whether decode work is the limit. C vs E is the same size and frame count in a different format — that tests whether Safari's GIF decoder is simply faster than its animated-WebP decoder, which is the real question.

If every animated option stutters and only F is smooth, the phone has no headroom for animation in Low Power Mode at all — and a still image is the honest answer, since the user has asked the OS to do less work.
