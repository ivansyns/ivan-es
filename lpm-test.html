Low Power Mode — which is smoother?

Turn Low Power Mode ON, then watch each for ~15 seconds. Neither uses a blend mode.

A — 12 fps, motion blur
480×596 · 120 frames · 1.85 MB · currently shipped
B — 24 fps, no blur
480×596 · 240 frames · 3.72 MB · twice the decode work
What we're testing. If B is clearly smoother, the phone has decode headroom and we ship it — it costs 1.9 MB more, below the fold, so it doesn't affect page load.

If B is the same or worse, the phone is decode-bound rather than frame-starved: Low Power Mode has throttled the CPU and 240 frames is more work than 120, not smoother motion. In that case more frames can never be the fix, and we drop the canvas size instead.
